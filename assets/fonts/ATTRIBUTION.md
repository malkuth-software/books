# Game text font candidates

These unmodified encoded font files are integration candidates for the portable game text adapters. Their exact hashes and source revisions are in `manifest.json`. Each family has its complete SIL Open Font License alongside the fonts.

- Libre Baskerville: Impallari Type, sourced from the Google Fonts repository at the recorded revision containing static regular and bold faces.
- Barlow Condensed: the Barlow Project Authors, sourced from Google Fonts at the recorded revision.
- Comic Neue: the Comic Neue Project Authors, sourced from Google Fonts at the recorded revision.
- Cousine: the Cousine Project Authors, matching the recorded GUI.Forms font fixture and upstream revision.
- Carlito: the Carlito Project Authors, matching the recorded GUI.Forms font fixture and upstream revision. The license preserves the Reserved Font Name Carlito.

The font names and credits are the upstream authors' work. Their inclusion does not establish final game typography or shared-renderer validation.
