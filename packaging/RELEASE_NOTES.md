The Pocket Library: a reading room of 746 books, each set as a printed book on the paper you choose and opened to the page you left. Its companion, PlaySuite (card games, puzzles and living scenes), is at https://github.com/malkuth-software/games.

If you read in PlaySuite's Pocket Library before, your places come with you: the first start copies them over.

Choose the download for your computer:

- Windows x64: run the setup installer, or extract the portable ZIP and open `Pocket Library/pocketlibrary.exe`.
- macOS Apple silicon, macOS 14 or later: install the PKG, or extract the ZIP and move `Pocket Library.app` to Applications. The app is signed ad hoc; it is not Developer ID signed or notarized.
- Linux x64 (amd64) or arm64, Ubuntu 24.04 or compatible: install the DEB using `sudo apt install ./pocketlibrary-*.deb`. The tar archive contains the same application and requires the system libraries declared by the DEB, including X11, ATK and ALSA.

Each platform is built and tested natively, and the packaged application is launched before it is published. Each book's edition and licence is on its About card. Your places are kept outside the installation directory and survive uninstalling the application.
